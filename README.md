# 🏦 Financial Risk Domain Analytics Dashboards

A comprehensive Power BI business intelligence suite containing two distinct dashboards dedicated to financial risk assessment, loan portfolio health, and home loan underwriting analysis. This repository demonstrates end-to-end data pipelines that transform sensitive credit metrics into strategic insights to mitigate portfolio defaults.

---

## 📌 Project Overview
Managing credit and underwriting risk is crucial for financial institutions. This repository consolidates two core analytical tracks under the financial risk domain:
1. **Risk Domain Tracker**: Focused on high-level portfolio health, macro credit risk categories, and non-performing loan analytics.
2. **Risk Task Analyzer**: Focused on underwriting dynamics, customer home loan risks, and asset-backed credit evaluations.

---

## 📂 Repository Structure
The project files are structured systematically into dedicated directories as follows (refer to `image_72c437.jpg`):

### 📁 1. Risk Domain Directory
*   **`Risk Domain/Data/`**: Source datasets for general credit and risk evaluations.
*   **`Risk Domain/Risk.pbix`**: Master Power BI file for core risk tracking.
*   **`Risk Domain/Risk.pdf`**: Printable high-quality report for corporate review.
*   **`Risk Domain/Dashboard.jpg`** & **`home-loan.png`**: Interface preview assets.

### 📁 2. Risk Task Directory
*   **`Risk task/Risk Data/`**: Extracted data tables optimizing operational risk validation.
*   **`Risk task/Risk Task.pbix`**: Dedicated Power BI modeling file for sub-task evaluations.
*   **`Risk task/Dashboard.jpg`**: Visual interface layout tracking operational figures.

## 🚀 Key Analytical Insights Covered
*   **Credit Portfolio Risk Profiles**: Isolating default probabilities across multiple user brackets.
*   **Operational Risk Mitigation**: Structural tracking of dynamic KPI matrices including NPL rates and total exposed values.
*   **Underwriting Performance**: Customer segmentation comparing income bands against home loan approval ratios.

---

## 🛠️ Tools & Technologies Used
*   **Power BI Desktop**: Data model mapping, advanced DAX implementation, and custom interface design.
*   **Power Query**: Schema mapping, structural data cleaning, handling missing variables, and data loading (ETL).
*   **DAX (Data Analysis Expressions)**: Dynamic financial risk formulas, custom running totals, and risk exposure percentages.
